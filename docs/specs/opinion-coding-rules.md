# 观点切分、主题边界与关系范围：试行规则 v0.1

2026-11-12。适用目标为[理解B表达并对照A](b-attention-distribution.md)。这是分析工作约定，不是论文评价标准、A含义确认或已实现的导入schema。规则已在两份已知评语的6个案例上校准，仍需新材料与专业使用检验。

本规则核对的是我们对数据的处理与解释，适用范围以[当前规格](b-attention-distribution.md#处理范围)为准。规则中的未知事项不自动生成论文事实或B专业结论审查任务；按本批出现的实际问题使用规则，不要求先解决所有理论歧义。

真实案例、来源区间、前后对应与待决事项仅保存在[本机校准包](../LOCAL_MATERIALS.md#calibration)。下文例句均为合成反例，不作为真实评语或效果测试。旧归纳、旧观点ID和报告不回改。

## 一次标注如何执行

1. 固定来源与普通分区、文字版本、分析规则版本；全文通读后圈出最小能理解的证据和必要上下文。
2. 列出“谁对什么对象，在什么范围/条件下，作何判断或建议，程度如何”。分别标理由、例子、条件、动作及总体处置，不先看A分区。
3. 先查是否已有同义判断；再按CUT规则决定分别设观点或保留复合观点。无论ID拆合，内容方面、动作、限定都要可分别定位。
4. 建立带角色、方向、作用范围与出处的关系。分开记录“文字明确连写”和“这种联系的含义已明确”，有歧义则保留解析。
5. 按THEME规则分配内容主题，说明依据到哪个方面；过程标签、理由链及修改路径另列。形成B解释后再作A对照。
6. 对照A按所声明方面逐关联说明；没有依据不补A/B意图。完成去重、条件和计数自查，留下已采用约定、未决项和修订来源。

最低交接内容：来源/版本与逐字证据；观点及内容方面；方向/程度/条件；主题定义与成员依据；类型关系及作用域；解释者/规则版本/核对状态；拆合去向和未知项。它是分析交接要求，不改变现有应用字段。

## 观点切分

### CUT-01 不同质量判断优先分开

触发：两部分对不同质量或对象作明确判断，各自可能成立、不成立，且能在共享上下文下分别核对。操作：本轮优先分别设观点，并保留共同语境。判断对象、程度或条件不同，应分别记录；不能靠句号、动词数或A跨项决定。

- 正例：“结构完整，但语言不规范”分两项；“基本”只归它实际修饰的判断。
- 反例：“信度检验已执行，所以信度已达标。”执行和达标不是同一命题；原话只有执行时不得补出达标。
- 例外：若原话只给一个宽泛判断，分析者想到的若干质量不能被补成多个原文明示观点。

### CUT-02 同一修改可保留动作组，方面不能省

触发：原话提出多个修改动作、实现方式或措辞替换。先应用CUT-01处理不同质量判断，再按以下顺序选择本轮默认切法，始终让各方面/动作可分别定位：

1. 同一断言的撤旧措辞/换新措辞视为一个改写目标，默认一个观点。
2. 某实现方向只是例示，或配套说明以“之”等绑定同一分类方案，默认保留在该方案内，并分别记录动作及限定。
3. 一个“补充”等共同建议谓词列出配套对象，且没有另起诊断、条件或强度，默认一个观点、多个动作；这是U08采用的切法。
4. 原话分别提出检验实施与结果解释等明确动作谓词、对象和核查目标，默认分别记录并保留相伴关系；这是U23/U24采用的切法。只有共用终极目的，不足以抹去这些区别。

这些是可复现的默认约定，不是逻辑上唯一ID数。若不同切法同样完整保留方面、限定和关系，可另存替代组织并声明粒度，不能仅凭数量判错。单看动词数或一个标点也不足以切分；不得合并到无法分别查证。

- 正例：“补足证据，可增加设计说明和检验”保留一个补证建议、两个动作；撤去强措辞并改用审慎措辞保留同一改写目标。
- 反例：“设计不适切，检验也用错了”含两个诊断，应按CUT-01分开；不能见两个动作就一律合并。
- 配套检验与结果解释涉及不同可核查目标时可分开；共同目的本身不足以合并。边界难定时，先保留可地址方面和另一种切法，不隐藏信息来凑观点数。

### CUT-03 清单、例子与备选措辞不逐项增加观点

触发：名词清单支撑同一判断，或“例如/比如/可考虑/等/或”给出实现方向。操作：保留清单、例示对象及各自限定，通常不另增观点。条件本身也不自动成为一条事实判断。

- 正例：“已完成清洗、培训和检验流程”可为一个执行完整性判断，三项分别留在流程清单。
- 反例：“例如身份可能影响结果；本研究已证实身份确有影响。”后句是明确的新判断，不能因前句有“例如”而删除它。
- “若不能补充”不是“当前确定不能补充”；“或”不自动建立排他选择。

### CUT-04 理由是否独立，取决于它是否另有判断内容

触发：一句内容既是理由，又自身明确评价另一质量。操作：可独立设观点，同时保留reason关系；若只是“因为不充分”等同义重述，附在原观点内。两者不是互斥选择。

- 正例：“结论过强，因为样本信息未交代”可保留结论尺度与信息汇报两项，后者支持前者。
- 反例：把“信息未交代”变成“没有实施研究”；出处不支持这种事实升级。
- 理由链成员可分别检索，不因此成为多个独立教师或同一主题里的额外表达次数。

### CUT-05 先去语义重复，再设新ID

触发：同一来源中，评价对象/范围、判断内容、方向、程度及条件一致，后一处只是再举实例或补依据。操作：优先追加原话、局部方面或上下文；保留旧ID去向。不同范围或新质量判断不因引文重合而自动合并。

总体—局部归并另须逐项检查：总体的对象范围确实包含该局部；局部未增加不同质量、条件、程度或缺陷机制；局部对象与证据仍分别可查。任一项未清时只能作有标记的工作归并，保留局部方面、归并理由和可另设局部观点的替代组织，不得说已证明两者同义。

- 正例：先说“所有结果段均未列出样本量”，后又指某结果段同一漏项，若范围包含且没有新含义，可补局部证据，不再计相同诊断。
- 反例：同一句同时评价结构和语言，引文相同不证明两个判断重复。
- 范围反例：全文批评“实证证据不足”，某节批评“论证表达无法承载推论”；是否同一缺陷未明，不能强制视作完全重复。可以在工作投影中归入同一容器，但须保留两方面及该归并待核，也允许分别设观点。
- 宽泛总结若只是重复细项，可保留为不新增关注量的摘要；不得同时把摘要、每个细项、理由和例子都相加成独立关注数。

### CUT-06 内容判断与总体处置分别记录

触发：出现刊用、退修、接受等流程建议。操作：单列流程/处置观点，并保留前提及其引用的修改范围。具体修改不因出现在“修改后刊用”之后就全变成刊用主题。

- 正例：“方法基本适切；完成下列修改后建议刊用”保留内容与处置两项，支持关系有依据才记。
- 反例：由“建议刊用”推出论文所有方面均获肯定，或把每条修改都算一条刊用关注。

## 主题边界

### THEME-01 按关注内容定义，不按章节、方向或共词分组

触发：形成或修订主题。操作：写明关注对象、评价问题、包含/排除条件及邻近主题；没有A也能说明定义。赞扬、批评、建议作为方向另记，同主题可以不同方向。

- 正例：统计标注与统计检验可以同属较宽统计组，但分别保留汇报格式与分析实施的子主题。
- 反例：只因都出现“文献”，把研究覆盖不足与格式不统一当成同一种缺陷。

### THEME-02 每个成员须有直接内容依据，允许有理由的多归属

触发：把观点加入主题。操作：指向相关方面及原话，说明它直接涉及什么。若只是为另一观点提供理由或同处一条修改链，仅保留上下文/关系链接，不能自动继承主题。

- 正例：补证建议的设计方面与检验方面分别进入不同子主题，仍是同一观点。
- 反例：因为“错字→强结论→补证”相邻，就把错字修改自动计为统计检验关注。

### THEME-03 上下位主题、问题链、流程是不同查看层

触发：需要宽概览与细区别。操作：子主题保留定义，父组按成员并集汇总；问题链用于论证/修改导航，流程另列。跨记录相近推论问题保留不同诊断与子方面。主题变宽或拆细必须版本化。

- 正例：代表性、差异归因和推广范围可联系查看；不据此说它们同一个问题或同一补救。
- 反例：把一个宽主题2/2覆盖与旧窄主题1/2直接比较，称为关注增长、准确率提高或遗漏修复。

### THEME-04 肯定与修改并存，不自动判矛盾

触发：同主题出现正面评价及修改建议。操作：比较对象、范围、程度、条件和时间；只有同一范围出现不兼容断言才提出候选冲突，仍保留依据。

- 正例：“总体基本规范，但表2仍需改格式”可同时成立。
- 反例：既不能以肯定吞掉具体修改，也不能仅因方向不同就判评审自相矛盾。

## 关系作用范围

### REL-01 关系需要端点角色、方向、证据和范围

触发：记录理由、解释、条件、并列、备选或主题联系。操作：明确谁支持谁、条件约束哪些动作、举例说明谁；逐关系保存出处/推断身份及已知/未知范围。多对象关系可用关系组表示，不能把无顺序成员列表当作已知方向。

- 正例：将“样本说明缺失”作为理由，将“强结论缺支撑”作为被支持判断。
- 反例：仅保存两个观点ID和“相关”，后续却把它解释成因果、赞同或同一主题。

### REL-02 条件只管有依据的目标，不补反向逻辑

触发：“若/如果/否则/至少”等。操作：保留原条件、对应动作、同时/备选关系与解析依据。条件写得明确不等于指代和作用范围已明确；可以逐字明确、含义待核。默认不推排他、充分性或反向命题。

- 正例：“不能补证时降级并说明局限”保留分支；不改成所有动作无条件累计，也不推“补证后必然可用强结论”。
- 反例：“无论能否补证，都须说明局限”中局限是无条件要求；不能沿用另一个案例的分支范围。
- 新补证分支与降级分支不是自动XOR；原话没有禁止补证后仍披露局限或审慎改写。

### REL-03 限定逐项归属，例子不升级为必做

触发：同句不同动作的强度、程度或例示限定不一致。操作：逐方面记录“基本/完整/可考虑/比如/建议”等，并保留其修饰目标。

- 正例：“建议调整分类，可考虑维度甲，并说明选例关系”保留调整建议、维度甲的例示身份及配套说明。
- 反例：把维度甲写成唯一必选；或把“可考虑”扩大到整句，删除配套说明。也不把“论证和阐释”擅译成新增统计实验。

### REL-04 连写、并列和共同主题不证明因果

触发：两个判断相邻，或分析者认为有关。操作：只确认原文足以支持的关系；因果、支持、必要性不明时，分别记连写事实与候选解释。

- 正例：“语句残缺，不能支持推广”可保留两个方面和关联未知，不认定补全语句即可支持推广。
- 反例：把“代表性不足，差异难归因”升级成所有研究中代表性不足必然导致归因失败。

### REL-05 指代与目的范围有歧义时保留并列解析

触发：“上述/之/有难度/避免偏差”等跨句关联。操作：列出有原话依据的最近候选指代、较宽候选和未决部分；选择工作读法时标为解释推断，不冒称原文明示唯一范围。没有依据不向整份评语扩展。

- 正例：句尾避免偏差可先保留为建议组的共同目的，同时注明是否只约束解释动作未知。
- 反例：将该目的排他地指定给一个动作，或让它无条件约束整篇论文。

## 未知、A对照与审计

### UNK-01 把问题交给能回答的来源

触发：A清单含义或B表达指向影响当前解释。操作：先按原话和上下文采用有依据的工作读法；A仅澄清确需其说明的原话范围，不替B指定意图。论文只按需帮助理解指代，论文事实及B专业判断是否正确不求解。未知身份或精确版本不阻塞记录分析；观点计数与主题命名由分析约定说明。

- 正例：向A问研究范式是否包括设计/选样原则；把B究竟要求何种p值格式保持未知。
- 反例：请A猜B没写出的具体检验、据A常识补全B的意图，或将A未列明视为A不重视。

### AUD-01 统计只描述明确层级和样本

触发：显示数量、覆盖或变化。操作：明确规则/主题版本和记录分母；同记录、观点、父组及多方面按集合去重。内容、流程、方面数分别展示；相关/部分/待核不合成明确覆盖。

- 正例：同一补证观点进入设计和统计两个子主题，在共同父组只计一次；两条记录不自动写成两位老师。
- 反例：把32个整理观点写成32项独立问题、专家一致性或总体重视权重；不把机械校验通过称为专业准确率。

## 出门前检查

- 所有明确质量判断、动作方面、条件、清单、例子和否定都有去向；所选观点可独立理解且能回到原话。
- 相同诊断的局部再现补证据；不同质量即使共句也不被吞并。复合动作的拆合约定已说明。
- 每个主题成员有直接依据；关系上下文没有自动增加主题覆盖；流程与内容统计分开。
- 每条条件/例示限定都有明确目标或未决范围；没有补出反向推论、必要因果或唯一技术方案。
- 只列影响当前处理的A含义、B表达歧义和分析约定，注明采用的读法与依据；范围外的论文事实未知不列成待办。改动留版本、依据和影响，不改历史输出。

规则优先级：忠实保留原话与限定 > 保留可分别核对的方面 > 避免重复计量 > 本轮ID与主题粒度约定。发生冲突先保留信息及分歧，不为得到唯一数量而删改。

合成反例中的数量只给出一种本轮投影，判定依据是必留方面、限定、作用范围与禁止的语义损失。允许的替代组织应明确记录，不能把数量不同本身当作失败。
