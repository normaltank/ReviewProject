# B内容与A位置候选分析 v1

更新：2026-11-15。本文落实用户在可复用工具讨论后确认的继续施工：A、B可变，原始B经过分析形成有证据的内容与位置候选，再由人回查、纠正、保存并直观查看。业务边界沿用[当前目标](b-attention-distribution.md)。

## 问题与结果

已交付的[输入与编辑 v1](b-attention-reuse.md)提供了跨批输入、人工建模、保存和汇总，但从原始B到观点、方面、主题、关系及A位置仍需人工填写。它是本轮基础，不能作为自动理解能力的交付证据。

本轮交付一条可实际运行的本机分析路径：读取当批B全部选定评语段落，先理解B内容，再独立对照当次A；产生逐字证据支持的待核候选；通过普通界面预览、接收、回查和纠正；保存后在明细和直观位置视图查看。生成候选不等于人工确认，不以模型输出格式正确宣称语义正确。

## 可观察行为与验收

1. 输入A的部分、条目、版本和B的记录数、标识、段落、分数均可变化；允许没有A先分析B。无A显示“未导入A”，不判为清单外。
2. 分析覆盖所选记录的全部普通评语段落。合并记录不能只读首段；超出上下文或处理能力时明确说明未处理范围，不静默截断。
3. B分析先于A对照，B阶段不读取A，不把A条目变成B的唯一分类框架。可形成新主题，保留套话、礼貌、总体判断、建议和处置性表达。
4. 一个观点可含多个方面，一个方面可同时对应多个A条目。主题位置、方向、表达性质、条件、备选路径和核查状态分开保存，不用几何距离决定归属。
5. B阶段保留影响理解的否定、程度、理由、目的、条件及备选关系；不把条件分支转成无条件要求，不推造专业结论。
6. A阶段只能对经校验的B对象提出位置与理由，不能改写B原话或B分析。A相关、对应、清单外和待核沿用当前契约；A不是评分标准，不要求分区互斥或穷尽。
7. 每个候选绑定来源记录、段落、逐字证据和字符位置。Unicode、重复原话有明确位置时可准确引用；没有足够位置消歧时拒绝该候选，不采用首个匹配。
8. 模型候选及位置一律待核，不能自行设为人工确认或工作结论。无依据项拒绝并列出原因；部分失败保留有效草稿和未完成范围。
9. 每次运行保留版本化输入快照、请求、原始响应、模型与提示/协议指纹、调用次数、用量及错误。完成、部分、失败、零候选只说明处理结果。
10. 提供可注入的响应回放用于工程测试，同时提供实际本机模型调用。回放、模拟和实际推理在记录中区分。
11. 生成和预览不修改正式分析包。接收候选通过现有attention.apply事务，新增稳定标识，不覆盖人工对象；重复接收幂等，源材料或A版本变化时拒绝过期导入。
12. 保存失败、重复操作、并发修订和重新打开均可解释并恢复。不能用“已生成补丁文件”代替数据库已导入的事实。
13. 普通界面允许选择范围、配置本机模型、生成、预览并接收为待核；无需为每批手写JSON或编写脚本。长操作不阻塞主线程，运行中切换目标不能把旧结果写入新包。
14. 直观视图按当批A组织参考区域，同时显示清单外、待核和未导入A。候选建议位置以待核样式显示，与正式已确认统计分开。
15. 同一方面可在多个区域出现，但记录计数去重。方向、表达和核查状态可查；A旧版本位置不能冒充当前A归属。
16. 从区域或对象可进入对应记录、原话、方面和关联理由，沿用编辑、保存与重开。视图和非图形明细使用一致筛选与分母。
17. 数量增长时先汇总再筛选、定位和钻取，不承诺无限记录或强迫全部点同时显示；能力边界和未处理范围清楚可见。
18. 用未参与实现的新A、新B验证完整路径，并分别报告工程有效性、实际语义忠实度和界面验收；不把代理演练称为用户体验或专业金标准。

## 实施决定

- 使用已安装本机模型资源，不新增付费服务、模型下载或云端回退。本轮实际推理验证仅使用合成材料。真实原件和当前真实分析包不参与测试，不自动发送或重算。
- 本机提供方仅支持明确回环地址，不跟随重定向、不读取环境代理、不自动重试。模型资源可以只读复用既有安装，运行状态和日志使用本任务独立目录；只管理可证实属于本工具的进程。
- 不复用旧抽取提示中排除总体判断、套话或处置表达的业务假设；复用适用的逐字校验、运行审计和保存事务。旧v3/v4协议保持兼容身份。
- 运行审计使用版本化旁文件，正式对象遵守现有attention数据契约。保留条件等原始结构，不塞入无关字段规避校验。
- 候选预览与正式统计分别表达。人工接收只授予待核身份，不能使建议位置自动成为已确认覆盖。
- 图形是内容与证据的入口；布局不是语义证据，区域不是A的权重或评分线。

## 验证边界

接口测试覆盖证据、失败、过期、事务与回放；真实合成本机调用验证语义路径；实际Tk操作和真实Chrome覆盖普通路径、回查与可视化。运行完整单测及scripts/check.ps1，不允许跳过替代验收。独立Spec与Standards审查固定版本，集中返修后复核，跟踪最终CI。

不在本轮增加专业复审、自动批准、A修订、评分预测、任意原始文档格式、付费后端或微调。输入整理和人工理解仍可使用已有入口；这不免除本轮实际分析能力与可视化的交付。
