# 统一网页工作台与 Windows 试用交付

用户于 2026-11-17 批准可点击关注图，随后要求统一网页入口、收拢工程目录、清理文档，并使用不同 A/B 输入验证后制作试用包。交付记录在 [#53](https://github.com/normaltank/ReviewProject/issues/53)。

## 工作台

- 双击 Windows 10/11 64 位试用包的启动器进入浏览器。新建、打开、录入、配置、分析、接收、读图、修改及保存均在网页完成。用户可关闭工作台，已保存分析和输入草稿可重开。
- 同一入口支持普通 B 原话、定位、分组、原分，和可选的 A 版本、部分及完整条目。支持受控普通来源选择、独立新建、草稿恢复及显式换 A。已保存目录与普通来源绑定受保护。
- 明确开始后才处理所选 B。网页使用已配置的 DeepSeek 服务。用户授权的私有试用包可内置共享凭据，个人凭据优先。共享凭据仅由显式构建输入加入该包。源码、Git、分析目录、候选审计、网页与导出文件不含密钥。
- 任务冻结目标包、范围与保存修订。选另一个包不会转移旧任务。生成、部分完成、失败、预览、接收保存与已核对分别呈现。结果由用户显式接收并保留待核身份。
- 随包可建立已保存合成示例。手工整理、阅读已有结果和导出可直接使用。构建白名单包含运行时、本地资产、说明、第三方许可和校验清单。

## 关注图与读评语

- 关注图是默认结果。按当批 A 清单的实际部分数绘制独立分区，主题及等大的记录标记表达出现情况。部分增多或名称较长时，保持各部分的名字与边界，可在图内继续滚动或聚焦。几何距离只服务排版。低频、空分区、未整理、处置、A 未明示、未定和待核可以辨认或进入明细。显示或关闭 A 时，B 的内容仍可查看。
- 点主题或标记可按同一筛选查解释和证据；同一来源跨多个位置联动，计数按记录去重。完整内容保留多主题、多 A、部分对应及独立的局部清单外范围。父子投影不增加记录数。详细说明放在所选对象旁，包括实际条件、否定、A 条文及对应理由。
- 主界面以原话、主题和内容定位，内部标识留在需查证的详情。逐条阅读从当前记录进入。宽屏可并看记录列表与原话；较窄屏幕仍能用键盘选择。1366×768 和 1440×900 的首屏应看到图、当前内容和关键操作，较长文本在独立区域滚动或展开。
- 图、逐条阅读、矩阵、关系明细和导出使用同一保存修订及筛选。导出的 SVG/PNG 写明范围、单位、分母、A 版本、图例与保存修订。保存成功后重开可复核，失败保留草稿。静态结果和历史候选可读，旧候选的接收受版本检查。

## 清理与验收

D 盘 `D:\Agent Workspace\ReviewProject` 保留规范源码、入口、原件和分析目录。切换前校验旧改动与本地证据的备份。只移除冗余工作树和不再使用的文件，已关闭的历史范围由 Git 和本地归档追溯。任务状态在 GitHub，试用待办见[清单](../../PROJECT_TODO.md)。

用不同 A/B 形状走同一网页入口。核对无 A、空或零命中、跨主题与 A 多重对应、条件、失效来源、候选隔离、保存重开和静态导出。使用合成输入及受控模型回放。最终 ZIP 在干净目录解压，以独立数据目录和系统环境运行实际 EXE，核对资源、配置、读写和退出。完整检查见[测试说明](../TESTING.md)。
