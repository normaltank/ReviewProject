# 统一网页工作台与可复用试用包

2026-11-18。用户明确要求统一入口到网页、收拢到`D:\Agent Workspace\ReviewProject`、删除冗余工作树/文件与过时文档、核对可变A/B复用能力，达到要求后制作解压即用试用包，并给出TODO清单。此决定替代最终保留Tk入口的安排，不替代此前已批准的关注图、同源联动、查证、纠正保存和静态导出。

## Problem Statement

结果图已获批准，但录入与分析仍经过独立Tk窗口，样式和入口割裂；开发文件与文档散在多工作树，使用者无法判断哪版可运行。试用者需要自己的A/B输入，而不是开发者当前固定材料的演示。

## Solution

本地启动器只启动回环网页工作台并打开浏览器。新建/打开、录入A/B及原分、配置分析、查看进度与待保存结果、显式接收、关注图/逐条阅读、纠正保存和静态导出在同一网页入口完成。保留既有输入/分析/事务底座，退役Tk呈现。最终开发与运行源收拢到指定D盘目录；Windows64位试用ZIP自带运行环境，不含真实材料、密钥或开发目录。

## User Stories

1. 我双击启动器即可进入网页，不需要先安装Python、开发依赖或PowerShell7。
2. 我能新建和打开自己的分析包；浏览选择分析目录或最近项目，不必学习工作树路径。
3. 我能录入任意数量的普通B评语、任意原分标签/原值和材料分组，保留原话、换行和Unicode。
4. 我能录入当批可选A的部分、条目、限定、版本；没有A也能先整理B，不固定当前实例数量。
5. 我能修改录入草稿、添加或移除条目，清楚知道何时只是草稿、何时建立了分析包。
6. 我能用支持的本地来源导入/读取材料，仍遵守普通分区、来源核验和原分保真约束。
7. 我能在网页配置自己的已授权分析服务；密钥只交本机凭据层，不进入结果HTML、分析包、日志或试用ZIP。
8. 我明确开始分析后才调用模型，看到真实进度、失败/部分完成及恢复入口；测试不新增真实付费请求。
9. 分析任务固定目标包、记录范围及修订；切换项目或A不把旧任务结果写进另一包。
10. 我能查看待保存结果、核对并显式接收，历史候选保持只读，不把生成结果冒称已保存。
11. 我继续使用已批准的主导轮廓、主题点簇、可选A参照、同源联动和具体解释，不能退回长排字列表。
12. 我从图或列表查看原话、条件/否定及A对应理由，纠正并保存后图、明细和导出一致。
13. 我能导出可独立理解的静态图；导出使用同一筛选、分母、A版本与保存修订。
14. 我能通过键盘及常见窗口尺寸完成主要任务，网页入口有一致字体、层级和明确动作。
15. 我能直接体验明确标注的合成示例，再建立自己的分析；示例不冒充专业金标。
16. 我能关闭本机工作台，已保存数据保留，未完成任务和草稿有实际状态；不留下无限后台服务。
17. 旧桌面入口能打开新工作台，最终试用包不弹Tk窗口。
18. 最终D盘目录保留实际源、运行入口和清楚的本地数据区；不覆盖另一会话或丢失独有材料。
19. 过时目标、重复说明和未统一术语从当前文档移除，当前目标、操作、契约、术语及任务记录有清楚入口。
20. 我能看到一份按实际证据标记已完成、未完成和待试用的TODO，不把历史撤回目标重列为待办。

## Implementation Decisions

- 优先在原生HTML/JS与标准库回环服务上补齐工作台。继续使用现有输入草稿、候选服务、冻结目标和SQLite事务，核心业务从Tk呈现模块提取；不维护两套录入/分析UI。
- 本轮明确授权新增工作台所需的本地网页路由，先前“不做全web编排”的范围限制因此更新；不扩展到云托管、账户系统、图数据库或新模型后端。
- 服务仅绑定回环地址，沿用本机写入会话的能力边界，校验改变状态的请求及来源；所有文件操作限明确选择的本地工作包。浏览器原生文件选择不属于被退役的Tk工作台。
- 自动分析继续采用现有DeepSeek服务/明确配置，试用者提供自己的凭据。没有凭据仍可打开示例、输入材料及使用已有人工纠正能力；不得宣称离线自带通用大模型。
- 冻结运行环境不能把`sys.executable`继续当系统Python启动`-m`子任务；核心操作优先进程内复用。启动器提供不打开浏览器的受控验收入口。
- 试用包按Windows10/11的64位环境制作，自带Python运行时/必要库及本地图形资源；浏览器使用系统默认浏览器。构建资源、许可证和样本列入明确白名单，不复制整个开发工作区。
- 工作树收拢前盘点独有改动及本地原件/分析包，保全必要证据与材料后删除冗余。托管worktree使用托管归档接口，递归删除/移动前验证绝对目标路径；不把用户数据当废文件。
- 当前用户承诺是可复用的试用工具，不是任意格式都可解析或任意评语都能自动准确解释。支持输入范围、失败处理和人工核对能力按实际验证说明。

## Testing Decisions

真实headless浏览器走网页新建/打开、可变A/B录入、分析队列/候选接收、读图/修改/保存/重开及导出；模型仅用受控合成回放，不触真实密钥/收费服务。使用不同A形状、不同B数量、无A、空/零命中、多主题/多A/局部圈外、条件否定与来源失效核对复用。

解压到干净目录，以不依赖开发Python/PYTHONPATH的环境启动实际打包程序；核对端口、页面、数据创建/恢复、示例、资源、退出及无Tk窗口。检查ZIP内容无真实数据、密钥、凭据缓存、工作树或测试日志。最终提交完成必要全量检查、独立两轴及视觉复核，文档链接有效。

## Out of Scope

不新增真实材料外发、付费模型调用、专业复审、评分预测、A标准修订或默认云服务。不自动合并main，不用一次工程验收保证所有未知输入的语义准确率。
