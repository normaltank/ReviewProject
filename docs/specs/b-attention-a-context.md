## 已核问题与范围

固定基线`64e3c369`已保存、展示A的部分名称和完整条目，但focused逐项A请求只包含条目文字，未传其所属部分名称。一个已知合成首评同时出现了“共同抽象主题”被扩成“具体属性局部对应”的语义错误；缺少分组语境是否造成该错误尚未证明。逐字坐标和保存事务正确，不为这处误读增加自动拒收规则。

本次补齐模型实际可见的原有A语境。继续使用同一focused、同一指定DS Flash及现有公开生成/预览/接收路径，不新增模型判断阶段或迁移第三方软件。

## 可观察行为

1. 每次focused A对照请求同时携带当前A完整条目和它实际所属部分的原样名称；条目、名称的大小写、Unicode及限定不改写。只提供该项所在部分，其他部分不混入本项语境。
2. 无部分、无归属或旧输入未声明部分时不推造分组；没有A时仍只分析B，不判清单外。不发送A定位字段中的本地路径。
3. 部分名称只用于理解，比较依据仍是该条目的实际内容。名称不新增要求、不改变条目效力，不成为必须满足全部内容的门槛；有据的跨部分交集仍可对应。合法partial/related、多A及剩余清单外内容保持。
4. 不改变B阶段输入、证据绑定、模型输出schema、网络/格式修复边界或保存契约。调用数不因补语境增加；已有接收、人工纠正、重开和过期行为保持。旧回放协议继续按其历史输入解释。
5. 候选仍待核。补齐语境与实际语义改善分别报告；不宣称由此消除所有A误读，也不把工程检查当准确率。
