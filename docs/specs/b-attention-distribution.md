# 当前目标与交付规格 B关注内容、联系与分布

更新：2026-11-13。**本文件以用户本轮画图、拓扑及套话讨论，以及最新“只处理已有数据，不审查B评得是否正确”的澄清为准。** 它是当前业务目标的唯一规格入口。历史计划、旧审计和外部AI回答不改变本规格。

<a id="当前最终目标"></a>

## 要得到的结果

**利用已有B评语、原分及按需论文语境，理解B关注什么、怎样表达、有哪些联系与差异，再与A已提供的关注方向对照，说明当前清单内外和本批分布，提供能看明细、回查原文、纠正并保存的结果，支持可选择的可视化查看。**

更准确地理解现状本身就是成果。套话、惯用表达、礼貌、转述和实质判断都可研究；允许根据材料形成有依据的一版解释，同时保留影响理解的歧义和其他读法，不等待证明B唯一的心理意图。

## 处理范围

本项目处理已有数据。B对论文事实、统计方法或修改方案所作判断，作为B表达的内容保留；**不审查B专业判断是否正确，不复算论文统计、不验证建议的科学有效性，也不承担论文质量复审。** 例如B说“缺少某参考文献”，我们可归纳其引用完整性关注，无需检查论文究竟是否缺失该文献。

需要核对的是我们的处理：原话和原分是否准确，切分、主题、关系、套话候选及A对应是否忠实于给定材料，有没有漏掉否定、程度、理由、条件或备选路径。这里的人工确认指确认分析记录，不是认可B的学术结论。

论文按需用于理解所评对象、指代、术语和上下文；原分用于帮助解释表达和差异。无需先取得精确送审版、教师身份、量表锚点或A权重才能开展记录层面的分析。材料关系未知时保留说明，不推造同人、同轮或评分原因。

当前默认任务不包括修订A、建设评分标准、预测分数、还原评审人权重或严宽、改变刊用决定，以及F0/Fd/Fg等旧实验。它们只有在用户另行提出对应任务时才进入范围。专业知识发现和技术选择服务于理解与处理数据，不扩成跨学科裁判B。

<a id="当前a工作参照"></a>

## A工作参照

采用用户向A询问后提供的[A关注方向原文](../LOCAL_MATERIALS.md#a-focus)，工作版本 `a-focus-20261112-01`。共5部分18项：引言5项、方法论3项、结果结论4项、总结2项、其他4项；项目定位索引沿用原文文件中的 `A-F01` 至 `A-F05`。

A清单只说明关注什么，不表示论文必须达到，也没有据此给定权重、合格线或扣分办法。“往往”“可以”“例如”“必要时”等限定保留。五部分不自动互斥、独立、等粒度或穷尽，“其他”也不是兜底区。

当前对照以已给清单为边界。内容清楚而清单未包含的B关注可留在清单外，不为猜测A潜在关注扩写清单。用户已明确：中文相关研究覆盖这一问不再问A，按当前A清单之外处理。其余问题逐项判断，不能一并撤下或一律提交A。只有A原话的含义确有歧义、并实质影响当前对应时，才集中列出具体实例和问题；A不代答B意图或论文事实。

旧课程13维24条及旧标准包保留历史和补充身份，不自动并入当前参照。A本人、A清单与某次A条目分别理解。

<a id="对象与关系"></a>

## 图中对象必须能表达的关系

B老师、评语记录、评价观点和主题是不同对象。一份评语可含多个观点，一个观点可含多个方面、多个主题和多个A关联，并同时含清单内、清单外或暂未定的内容。不能把老师、整份评语或复合观点强制变成一个只有唯一位置的点。

主题相近、判断方向、理由、条件、例子及备选动作分别保留。有共同主题不表示判断相同；“结构清晰”与“论证薄弱”也不必然矛盾。连接应说明涉及哪段内容及为什么这样理解。模型或图形能表达这些实际差别即可，不以穷尽所有领域、本体完备或唯一切分数量为前提。

套话候选与本次表达的作用分别说明。通用措辞可以有实际作用，具体措辞也可能只是转述；肯定、重复或句子长短不单独决定是否保留。允许按有说明的规则筛选查看，原话和解释依据仍可回查。

<a id="完整业务路径"></a>

## 默认工作路径

**原话与原分 → B关注及表达功能 → 主题和关系 → 与A对照 → 本批分布 → 明细、可视化及回查纠正。**

1. 明确本批材料、记录编号和A版本，复用已有原件和抽取结果；需要时补看论文语境。
2. 整理B观点和主题，保留原话中的对象、程度、理由、否定、条件、例子和替代方案。先理解B自身内容，再作A对照。
3. 每个具体方面允许对应0至多个A条目，说明对应、部分对应、清单外或暂未定的依据；不因B判断是否正确改变这项内容关系。
4. 汇总本批关注的出现与联系，返回具体记录查看；显示套话候选、功能解释和原分时保留它们的不同含义。
5. 用户可以纠正切分、主题或关联，保存后重开；相应明细、计数和图形保持一致。

最低限度的结果包括来源与原话、原分、关注/主题、必要的关系和限定、A对应及理由、修改记录。未出现或对当前解释无影响的附加字段允许为空，不把字段越多或图越复杂视为完成得更好。

## 分布口径

主要显示不同评语记录覆盖数及本批分母，辅助显示观点数、材料分组和解释状态。副本、重跑和同一观点的多方面不增加独立记录；教师、稿件或轮次只有关系可核实时才按相应单位分析。未知身份不妨碍按记录统计。

A五部分按记录取并集，不直接相加子项；多主题、多A对应允许重叠，合计可超过记录数。主题与条件/流程关系不能混成同一种频率排名。相关、部分对应和暂未定不合计称明确覆盖。

数字描述本批表达，不表示B群体的重要性、论文优劣或A权重。主题宽窄、切分和筛选规则与计数一起说明；未提及不代表不关注。说明到足以正确理解本批数字即可，不为此自动建立测量模型或启动总体效果实验。

<a id="最终交付与可视化选项"></a>

## 交付及验收

1. A18条及所选B原话、原分准确可查，原文限定完整；A关注未被改成强制标准。
2. 主题、关系、套话候选和解释有材料依据，允许重叠和有说明的歧义；检查遗漏、误合及限定丢失。
3. B与A的具体对应及清单外内容可追到明细；分布有分母、可复算，不因副本、多重映射或分组重复计量。
4. 不打开图形也能理解和回查结果；另有可选择的矩阵、关系图等视图，清楚说明点、线、颜色和数量含义。
5. 修改与保存后，明细、统计和可视化同步，历史可追；查看或下载不冒称已经保存。

验收核对的是本项目对数据的处理和呈现。证明B判断正确、取得专业金标、评审人身份全部确认、建立评分锚点、证明节省工时或改变刊用决定，都不是提供当前分析的前置条件。需要更大规模自动化或用户收益比较时，再按实际问题安排适量验证。
