# B 关注内容、关系与分布

## 目标

出版社已有外部高校老师（B）对论文的文字评语、原分和可供回查的论文材料。内部专家（A）提供一份本批可用的关注清单。工具帮助阅读者从 B 原话理解谈到了哪些问题、怎样表达、评价或建议有哪些理由和限定。随后与当批 A 清单对照，并显示本批评语中各主题和对应关系出现在哪里。

同一套软件接受每批独立的材料。B 记录、普通分区、材料分组和原分可变，A 的部分、条目、文字及版本可变，也可先无 A 整理 B。读者可以核对分析是否忠实于材料，纠正并保存。论文和原分只在有助于理解语境时使用。

## 材料与解释

- 保留 B 原话、原分及出处。记录、观点、观点方面和主题各有身份。一份评语可以包含多个观点，同一观点可有多个方面，同一方面可涉及多个主题或 A 条目。
- 先理解 B，再对照 A。保留影响含义的对象、否定、程度、原因、例子、条件及备选动作。套话候选和它在本次表达的实际作用分别记录。条件或动作关系须说明端点作用和依据，共同主题本身只说明内容相近。
- A 使用当批清单的完整条文及限定。部分可能交叠，条目可以重复涉及同类主题。对照按具体方面和语义范围，允许明确、部分、相关或未定，也允许有据指出本版未明示。旧版本和待核关联保留历史与核对状态。无 A 时，未作 A 对照。
- 工作解释可以保留歧义和其他读法。分析核对检查转录、切分、归纳、关系和对照的忠实度。工具保留 B 的专业判断供阅读，专业复审由原工作流程承担。

## 分布口径

以当前筛选中的不同评语记录为分母。主题和 A 部分按记录取并集。可同时计入多个主题及 A 条目，所以行数可以重叠；同一记录在同一行只计一次。观点、方面和处置另列辅助数。选择原话或切换阅读对象时分母保持，选择记录或材料组时分母更新，表达筛选只影响命中。

区分无记录、零命中、尚未整理、来源失效和 A 未提供。数量描述本批表达；结论范围随原始样本、所用 A 版本及主题定义。教师或轮次未知时仍可按记录统计。

## 使用与验收

工作路径为录入或导入 → B 内容和关系 → A 对照 → 关注图与明细 → 回查纠正并保存。换 A 采用显式版本接续，原 B 和历史保留。变更 B 原话、来源或批次应另建分析。已失效的绑定保留旧快照，修复原绑定或另建分析后再继续。

验证至少使用不同 A 形状和 B 内容的合成输入，以及无 A、零命中、多主题、多 A、局部未明示和来源失效。检查保存重开一致，静态图与当前分布同范围。已有本地案例和证据见[材料定位](../LOCAL_MATERIALS.md)，录入和界面验收见[网页与试用交付](web-workbench-trial.md)。
