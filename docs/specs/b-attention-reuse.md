# 可复用的B关注分析工具 · v1

日期：2026-11-14。补充[业务规格](b-attention-distribution.md)，落实用户最新确认：未来A、B输入都可能变化，交付可反复使用的工具。此处规定输入与复用路径；关注含义、统计及权限沿用业务规格和既有契约。

## 问题

已有底座可以处理不同A、B和原分，保存后能汇总、编辑和回查。但普通建包、录入A仍要求准备约定JSON，当前新导读又绑定某一批冻结结果。用户换材料时仍需要工程师编写清单或专用报告脚本，无法靠同一个工具完成下一次分析。

## 解决方式

提供本机的输入准备与建包入口，录入完整A条目、B原话和任意原分，或选择已导入工作区的普通分区，直接建立独立分析。沿用已有观点、主题、关系、A对应和草稿应用流程；概览、明细、筛选及可选图形均从同一保存修订生成。当前真实导读保留为冻结样例。

## 用户故事

1. 作为分析者，我要在普通界面新建另一批材料，以便重复使用同一工具。
2. 作为分析者，我要先录入B、暂不提供A，以便先理解B自身表达。
3. 作为分析者，我要逐条粘贴原话并填写定位和可见性，以便准确回查。
4. 作为分析者，我要为每条记录录入零至多个原分标签和值，以便保留不同表式的原分。
5. 作为分析者，我要选择既有工作区的普通分区，以便复用已核验抽取而不带入私密区。
6. 作为分析者，我要录入任意数量的A部分、条目及完整原文，以便使用本次参照。
7. 作为分析者，我要查看并修改待建包清单，以便在冻结前纠正录入错误。
8. 作为分析者，我要明确看见新包的位置与输入快照，以便再次打开及备份。
9. 作为分析者，我要在同一包中显式导入新的A版本，以便保留B、分析身份和历史，并核对旧对应。
10. 作为分析者，我要为变化的B建立独立分析，以便保留旧结果，不把旧观点偷接到新原话。
11. 作为分析者，我要在未分析时看见空态，以便区分材料已导入与内容已理解。
12. 作为分析者，我要查看当前批规模、主题、关系与A分布，并回到命中原话，以便理解数字的依据。
13. 作为分析者，我要在纠正保存后看到同修订结果，以便区分下载草稿与数据库提交。
14. 作为分析者，我要在来源失效时看到旧快照和下一步，以便保护已有分析。
15. 作为维护者，我要用完全不同的合成输入走同一界面，以便验证软件没有依赖当前样本的数量、别名或专用脚本。

## 实施决定

- 复用独立关注分析引擎、A版本事务、保存态汇总、普通编辑器和本机控制器。输入准备是中性的录入和来源选择，不引入framework依赖或新的语义模型。
- B转录保留Unicode、换行、空格、任意原分标签/原值和显式可见性。工作区选择只列普通分区，保留原定位与权限。记录身份和去重沿用既有来源契约。
- 新包保存独立的B输入快照和A版本输入；换A不通过改写绑定B的初始混合清单实现。建包前检查完整清单，既有目录和文件受保护，失败和恢复遵循既有原子保存约定。
- A可为空；有A时保留完整条目、版本及部分结构。普通入口支持A准备与显式导入，不要求用户编程、填写GUID或手工JSON。
- B换批或更正通过新建独立分析完成，旧包保持其身份和历史。旧包来源变化继续冻结并拒绝普通编辑，显示还原原绑定或另建分析的操作；原包内B换源及旧标注迁移尚未实现，不在此次冒称具备。
- 概览使用当前保存态的集合及分母，只陈述可复算事实；人工解释与精选案例属于各批内容，缺省为空。界面文案不写固定A部分数、记录数、主题数、旧别名或真实本地目录。
- 新输入不会自动得到已理解、已核对的观点。现有普通表单支持整理，模型自动分析是另行能力，不能以复制样例发现冒充。

## 验证决定

优先在已有控制器、保存包及真实浏览器交互处验证外部行为，复用现有合成测试工具。两组验收数据从普通输入入口建包，所用代码和步骤一致；探针中程序化生成保存态不能代替这项端到端验收。

- 场景S1：无A、2条不同B，含Unicode、重复句、一条自由原分及一条无分；建包后从普通表单新增观点/主题，下载、应用、重开，N=2，空A和原分准确。
- 场景S2：3部分/3条A（含空部分和零命中条目）、3条不同B、原分数不同；补录观点、主题、关系和A对应，保存后同修订概览/明细/矩阵/图回查一致。
- 在S2中普通录入新的A版本（部分数、条目数、文本变化），B与观点身份不变、旧A有历史、旧对应待核；纠正后保存重新显示。S1不受影响。
- 更正B原话或增删记录后从同一输入入口另建独立包，旧包文件、身份及历史不变；改变旧包绑定文件并恢复时保留旧快照、标待核、拒编辑，恢复原字节后可重开。
- 全套合成检查按项目命令运行，真实Chrome验证下载/应用往返、无图回查和新输入空态。结果需绑定最终提交；独立Spec与Standards审查覆盖相同基线与目标。

## 范围边界

原包内B替换及跨版本标注迁移、任意Word表式的自动解析、新大模型调用与自动长篇解释、论文或B专业复审、用户本人体验和节省工时证明另行安排。真实原件、分析、截图和派生产物继续仅留本地可信目录。

## 已有成果

现有核心已通过两组不同形状的合成接口/保存态探针；这证明通用底座可复用，未证明普通录入的完整路径已实现。当前真实批次与冻结导读作为一次验收实例保留，不是新输入的默认结果。施工顺序、来源证据和逐项验收见[施工计划](../plans/b-attention-reuse-construction.md)。
