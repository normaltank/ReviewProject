# 已批准关注图与统一阅读交付

2026-11-17。用户对当前对话中的可点击关注图明确回复“可以可以可以，很棒，按这个做就行了”。本规格固定该方向，并沿用[汇总需求](attention-summary-visualization.md)与[体验规格](attention-experience.md)的业务、保存和界面边界。旧focus-v1、生成图和失败的首屏分数保留历史身份，不作为本轮验收参照。

## Problem Statement

先前汇总主要是文字排布，陌生编号无法辨认材料，泛泛说明占空间，具体条件和对应理由反而不清楚。网页字号、纵向布局与本机弹窗割裂，桌面入口仍打开旧版本。需要把已批准的可点击图接入真实保存态，完成从总览、查原话、纠正保存到再次阅读的完整路径。

## Solution

结果页以可探索的关注图组织本批B内容：A作为可选参照，主题旁的等大记录标记显示实际覆盖，未明示、对应未定和未处理分别可见。选中标记即读原话、限定、A条文及具体对应理由，同份评语跨主题或区域的所有位置联动。逐条阅读沿相同选择和证据进入，修改保存沿现有事务完成。网页和本机录入、分析窗口使用正常中文字体和清楚的动作名称；验收后桌面入口指向本轮运行树。

## User Stories

1. 作为阅读者，我要在总览看到B主题、记录覆盖数和本批分母，以便直接理解分布。
2. 我要用主题和原话识别内容，不必先理解R01等内部编号；来源标识仍可在材料详情查到。
3. 我要选择标记后读到具体关注、完整原话和精确证据范围，以便核对解释。
4. 我要看见实际条件、否定、理由及备选，不用“有条件”等抽象标签代替含义。
5. 我要知道与哪一版A的哪一段有何交集，以及明确、部分、相关、未定、待核和清单未明示的具体理由。
6. 同一评语跨主题或A位置时，我要看到它们属于同一来源，记录计数仍取并集。
7. 同一主题中的多方面、多A关系及局部清单外范围都要保留，不能只选第一项。
8. 我要关闭A参照后仍看见完整B内容；没有A不等于全部清单外。
9. A部分及条目按实际输入组织，空部分可辨认，不能固定三部分、六评语或任何原型文本。
10. 我要辨认父子主题、未归主题内容和总体处置；不把父子重复投影或总体处置充当额外内容覆盖。
11. 低频主题、未处理、没有当前对应及来源失效要能查到，不能为画面整洁消失。
12. 我要以同一筛选集合、分母和保存修订阅读图、明细、矩阵及局部关系，切换选择不改变分母。
13. 我要区分N=0和N>0零命中；空白不冒称完全不关注。
14. 我要从图进入当前方面的修改，保存重开后图和明细一致；不完整输入、失败和冲突保留草稿。
15. 我要逐条阅读并来回切换原话、关注和A依据，图上选择和阅读游标一致。
16. 我要在1366×768及1440×900、100%缩放下看见主要内容和下一步；长材料及大量详情在各自阅读区域展开或滚动。
17. 我要通过键盘完成选择、回查和修改，窄屏不依赖把中文缩小或遮住低频内容。
18. 我要导出清楚的静态关注图，包含范围、单位、N、A版本、必要图例和保存修订；内容与当前筛选一致，主要含义不依赖悬停。
19. 静态结果及历史候选仍遵守只读/导草稿边界，不出现误写旧修订的入口。
20. 本机录入以当前原文和明确的加入/保存动作组织，原分、来源及A附加信息按需进入，避免套层滚动和重复说明。
21. 本机分析突出范围、开始、进度及明确的待保存/已保存结果入口；配置、历史、完整审计按需进入。
22. 我不希望施工验证反复在工作桌面弹窗；自动GUI检查须在私有桌面运行，浏览器启动在测试边界替换。
23. 验收后我通过原桌面入口打开新版本，不需要记住工作树名称；旧材料和其他会话不被覆盖。

## Implementation Decisions

- 本轮以用户已批准的HTML交互原型为构图和行为参照，采用代码驱动实施；不再生成风格候选，不伪造旧图片门槛通过。近黑、正常中文无衬线、克制标题、细线和直接的内容解释保持。
- 继续使用保存态汇总、有效位置投影、记录/方面身份和现有编辑事件。按记录并集计算主题及区域覆盖；原型的来源、文字、A部分和坐标常量不进入产品。
- A区域是当前参照的组织示意，多重对应保留关联或投影身份；几何大小、远近不承载未测量的重要性或语义距离。多种状态不可压成原型四种符号之一而丢失。
- 优先复用SVG/HTML。布局确有缺口才采用小型D3模块并随包提供许可和本地资源；不增加远程CDN依赖、三维坐标、图数据库、前端框架或模型服务。
- 保存与候选预览继续共用现有回环会话、事务和投影。候选覆盖层和无脚本的可读结果仍可达。
- 本机呈现可直接重排，保留Controller、输入草稿、冻结A目标、队列和服务归属。私有桌面启动器不得切换用户输入桌面，失败不得回退弹窗；窗口截图按句柄捕获，不抓用户屏幕。
- 已验证版本的桌面快捷方式采用备份后更新工作目录的方式切换，不复制或覆盖旧工作树及真实分析包。本轮任务树作为保留运行树，不在清理时归档。

## Testing Decisions

沿现有公开路径验证：合成输入建立包、保存态渲染、真实headless浏览器选择/回查/修改/保存/恢复，及原生输入和候选队列。只测可观察结果，不测布局实现细节或复写实现。

覆盖可变A结构、多主题/多A/局部清单外、同原话不同来源、主题层级、处置、无A、未归主题、空N/零命中、条件否定、来源/A失效和逐项待核。核对读图数与独立手算集合；保存重开及静态导出对应同一修订和筛选。

网页与本机目标尺寸批量截图，核对正常字号、键盘、按钮实际结果、内容溢出和主要操作可见。所有Tk和GUI截图运行在私有桌面，记录输入桌面名称前后相同；测试对系统默认浏览器启动做边界替换，真实浏览器回归继续用headless Chrome。

最终集成提交完成完整零跳过检查和独立Standards/Spec审查，并对批准原型做独立视觉/交互复核。测试通过、视觉通过、语义准确和用户使用效果分开报告。

## Out of Scope

不新增真实材料上传、模型推理、付费后端、专业复审、评分预测或A标准修订；不自动合并main。不把原型验证或本轮工程检查称为任意未来输入的语义准确率证明。
