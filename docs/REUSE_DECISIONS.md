# 复用决策 · 2026-11-13

当前业务依据为[B关注内容、联系与分布](specs/b-attention-distribution.md)。本页从既有本地试用提取工程维护决定；完整历史、真实错漏及授权证据留在[本地工程资料](LOCAL_MATERIALS.md#engineering-evidence)。当前积压整理和main交付状态见[STATE](STATE.md)，不把选型、工程接入、语义准确率和用户收益混为一项完成。

## 继续采用的底座

- **原件与结构化输入**：保留python-docx薄适配及标准库CSV/JSON，冻结字节、原分字符串、解析状态和Unicode证据区间。特殊表型或权限歧义按契约拒收并回原件判断，继续使用合成输入做仓库回归。
- **保存与普通纠正**：保留SQLite事务、JSON补丁、静态HTML/原生JS、Tkinter本机入口；复用修订冲突、幂等、原子拒收、历史、恢复和来源定位。下载是草稿导出，应用成功才保存；HTML及派生产物继承来源权限。
- **候选抽取**：既有LangExtract接口继续使用严格逐字适配。获准批次可选Flash为候选辅助，本机Qwen3-4B保留必须本机场景的备选；段落/窄规则作为简单对照。实际调用配置与CLI默认值以对应代码和运行记录为准，不因选型推荐静默改共享默认。v3默认与显式v4试验并存，定位通过不能自动确认语义。
- **证据查找**：已有FastEmbed/BGE-small-zh-v1.5 ONNX及NumPy路径和显式词面方法继续作为可选本机辅助，仅查旧审核包所选普通观点证据。事先准备模型文件，运行时不下载或静默换方法。相关性不证明同立场、覆盖、矛盾或论文事实；当前无通用受控论文全文库。
- **条件与离线重放**：保留独立单条件动作 `conditional_actions` 与至少两支的 `alternatives` 区别。`replay-grounding` 显式生成新artifact，之后才按原入口导入/恢复；保留旧运行和partial等状态，不冒称模型当时直接输出新字段。

根目录依赖清单和代码是实际版本来源：基础环境为 `requirements.txt`，模型/检索另用对应可选清单。可选组件不成为人工主导路径或本批B分析的前置。

## 新关注流程的复用边界

按[正式计划](plans/b-attention-distribution-construction.md)复用证据、事务、来源快照和编辑机械能力；旧batch仍要求framework，不能改名冒充新中性入口。无framework分析包、跨记录主题/稳定方面、表达作用与套话候选分离、带作用域关系、A18对应、记录并集和可选图形按[关注分析契约](ATTENTION_CONTRACT.md)及其后续汇总接口实施；实际集成与验收状态见对应Issue/PR和STATE。旧schema和条款决定语义继续保持兼容。

已有独立工作稿可迁入，保留旧别名与新身份映射并核对重复片段及关系作用域。A18是内容参照，不转为强制条款；中文相关研究覆盖留在清单外；原分和论文只按需解释语境，分析确认表示处理忠实。

## 暂不新增的组件与结论

继续保留现有复核流程，不迁移第二标注平台，不因没有可靠自动理解而等待交付人工纠正闭环。Label Studio/INCEpTION曾有文档、预填或实验桥等不同范围探查；尚无同任务专业工时、普通关系编辑及完整回填收益证据支持迁移。DSH隔离调用层的mock验证不等于本产品真实抽取采用它。

本批不引入向量数据库、图数据库、自动主题/标准批准器、微调或评分优化器。只有真实瓶颈和适量同任务比较支持时再评估。历史已知开发例、合成控制、代理匿名诊断及测试数量均不是独立专业金标；逐字引用仍可能遗漏、误合或错置理由/条件。

原模型响应、失败、旧对照、预算和材料边界继续留本地。持有密钥或历史批准不授权新费用/外发；本轮不做新AI征询。当前#6不重做平台综述或模型比较，先整理可复验工程底座，再执行既有T1—T6。
