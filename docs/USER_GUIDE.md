# 使用指南

## 打开工作台

在 Windows 上解压整个试用包，双击 `ReviewProject.exe`。保留同目录的 `_internal` 文件夹。工作台在系统浏览器打开。初次使用可以点**建立合成示例**，再点**关注图与逐条阅读**。示例已经填入虚构评语和示范解释，可直接尝试修改，无需开始模型分析。

## 用自己的材料

1. 点**录入B原话和可选A**，填写新的本机分析目录。每条 B 评语照原样粘贴，保留换行。可补充材料分组、出处和任意原分标签和值。已有受支持的本机来源工作区可以选取普通分区。
2. 有 A 清单时，填写版本、部分和条文原话。保留“可以”“通常”等限定。也可以先无 A 整理 B。**保存输入草稿**留待继续，**建立分析**把本批材料封存在独立分析目录。
3. 已有分析从**打开分析**选取包含 `attention.sqlite3` 的目录。补充或替换 A 时，先在录入页准备新版本，再在**维护当前分析**中核对目标和条文，再点**采用此A版本**。更正 B 原话或换批时另建分析。

## 开始分析与核对

在当前分析中勾选要处理的评语，然后点**开始分析**。这一步把所选普通评语原话及当前 A 条文发送给 DeepSeek。私有试用包可提供共享配置，个人配置优先。可在**分析设置**保存个人密钥，也可直接进入结果手工整理。结果页、保存的分析和导出文件都不含密钥。

任务完成后先打开待保存结果。核对原话、条件、解释和未完成范围，再按需**接收并保存**。接收会保存待核结果。分析过程中项目、A 或修订发生变化时，请回到原包核对任务状态；过期结果需要重新生成。

## 读图、修改和分享

- **关注分布**按当前筛选显示 B 主题和记录覆盖数。A 参照开启时，分区使用当批的部分，可以看出明确对应、部分对应、相关、待核和本版 A 未明示。关闭 A 参照后可以单独读 B。
- 点一个标记查看这份评语的原话和这次关注的解释。同一评语分布到多个位置时，选中后可以一起找到。章节旁的覆盖数以评语记录为单位，同一份评语在同一统计项中只计一次。详细口径见[分布规格](specs/b-attention-distribution.md#分布口径)。
- **逐条阅读**适合连续核对材料。查看原话高亮、条件、否定、A 条文和对应理由。纠正后点**保存修改**，核对页面中的新修订。遇到冲突先保留修改内容，重新打开当前修订再处理。
- **导出 SVG**或**导出 PNG**保留当前筛选的图、图例、范围、A 版本和保存修订。直接打开分析目录中的静态 `attention.html` 可以阅读、导出图或导出修改草稿。需要持久保存时从工作台打开分析。视图文件丢失或过期时，在**维护当前分析**中点**恢复已保存视图**。

分析包是整个目录。用网页**关闭工作台**后复制完整目录；使用了外部绑定来源的，也保留原文件及路径关系。
