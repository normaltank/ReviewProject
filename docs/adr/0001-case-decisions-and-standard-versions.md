# 个案决定与通用标准分开，新标准默认不追溯适用

用户在Q12、Q13确认：针对某篇论文接受老师的修改建议，记为个案处理决定，可以成为修订线索；变为通用要求需要另行审议，两类决定分别记录、分别确认。

正式获批的新标准默认用于生效后新进入流程的论文；已经在审稿的论文沿用原要求，确需切换由人工决定并记录原因。历史评分和意见保留原样，用新标准重新比较时另存结果。

这个选择保留原流程的可预期性和可追溯性，代价是可能同时存在适用不同版本的在审稿件，需要明确记录其实际采用的要求。它是已确认的业务规则；本记录没有发布正式标准，也不表示当前代码已经实现版本切换或历史重评流程。
