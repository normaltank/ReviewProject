# 阅读与修改分析结果

打开结果，先看每份评语的关注点及与A关注清单的对应。完整解释、原话、原分和理由展开查看；待核、未完成和来源变化会明确提示。

- **查看分布图**：查看当批A下的对应位置，点击图形可回查具体解释。一个方面可对应多个位置，位置和面积不表示分数或权重。
- **查看统计**：按需看主题、A部分/条目和记录分布；各类可以重叠，不能直接相加。
- **查看原话与修改**：核对原文或纠正解释。条件、关联、拆合等工具在需要时展开。

记录、材料和表达筛选、更多图表集中在**更多查看方式**。记录或材料筛选会改变分母，表达筛选保留分母。完整解释、A原文与保存历史仍可单独展开。

修改后点击**暂存这条修改**，再**下载修改文件**。回本机窗口展开**保存修改与更换关注清单**，点击**保存下载的修改并查看**；保存成功会自动打开最新结果。下载还不等于保存，页面会保留未保存提醒。

分析前的结果页会明确说明尚未保存；保存后的内容仍需核对。工程回放始终标明非实际推理，处理明细和原始运行记录按需查询。工具不额外生成一套摘要，也不自动跨记录归并主题。

输入和换批见[输入说明](ATTENTION_INPUT.md)，生成与保存见[分析说明](ATTENTION_CANDIDATES.md)，数据规则见[契约](ATTENTION_CONTRACT.md)。
