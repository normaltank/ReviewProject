# 阅读B关注，按需回查与纠正

打开关注页，先读“已保存的B关注”。每条记录列出已有的方面解释与核对状态，展开即可查看完整原话、原分、证据和限定。页面不另外生成总结或自动归并主题；跨记录归纳仍可在主题编辑中整理。

页面上方显示保存修订、当前记录范围和分母、待核数量、来源状态及草稿状态。记录或材料筛选改变分母，表达筛选保留分母；候选不进入保存统计。来源失效和未完成范围不因折叠而消失。

- **阅读B关注**：按记录查看已有解释，展开一条查看依据。
- **主题与统计**：按需打开主题、A部分/条目及各类统计；记录去重，各项可重叠。
- **对照A与位置图**：查看当批A下的具体对应与范围理由。一个方面可以有多个位置；无A不表示清单外。位置、面积和距离不表示评分或权重。
- **原话、原分与纠正**：从具体方面选择“在原话与编辑区核对”，或打开页首同名入口。已有未加入草稿的更改会受到保护。

修改后先加入草稿、下载，再回本机窗口应用并恢复重开。上方始终区分“未加入草稿”“未应用草稿”和已保存修订；下载不会更新保存结果。完整解释、A原文和保存历史保留在页末展开项。

候选页先显示候选B解释，全部仍待核。处理状态、未完成数量和输入有效性直接显示；“处理范围与运行明细”可查看完整覆盖、拒收、格式修复和调用记录。历史候选明确标明接收修订，不代表此后的人工解释。下方保存快照属于生成时版本；收起它也不会隐藏当前页面的未保存更改。

所有展开项可用键盘操作。点击原文、方面或图形链接以及打开带位置的链接时，会展开对应内容；查看不会更改分析。

输入和换批见[输入说明](ATTENTION_INPUT.md)，生成与接收见[候选说明](ATTENTION_CANDIDATES.md)，保存与失效规则见[契约](ATTENTION_CONTRACT.md)。
