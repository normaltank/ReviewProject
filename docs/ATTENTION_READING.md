# 阅读与修改分析结果

打开结果，先看每份评语的关注点及与A关注清单的对应。完整解释、原话、原分和理由展开查看；待核、未完成和来源变化会明确提示。

- **查看分布图**：查看当批A下的对应位置，点击图形可回查具体解释。位置和面积不表示分数或权重。
- **查看统计**：按需看主题、A部分/条目和记录分布；各类可以重叠，不能直接相加。
- **查看原话与修改**：核对原文或纠正解释。条件、关联、拆合等工具需要时展开。

记录、材料和表达筛选、更多图表集中在**更多查看方式**。记录或材料筛选会改变分母，表达筛选保留分母。A原文与保存历史可单独展开。

在本机窗口打开结果后，修改表单并点击**保存修改**即可提交；不必先逐项暂存或搬运下载文件。保存会一并收集当前有效表单及已有草稿，成功后打开最新修订。修改者声明、理由、来源定位及导出工具按需展开；默认审计声明仍会保留。

切换记录、观点或关联时，已填写的有效内容会保留；必填信息不完整时会提示并阻止切换。修订冲突、来源变化、桌面会话关闭或保存失败时，草稿留在当前页面。刷新、关闭页面或重新打开前，先保存或导出草稿；页面内存不是持久备份。

保持本机窗口运行。它为每个结果页绑定一个分析包，主窗口换包不会让旧页写到新包。候选预览及历史快照只供阅读，不作为旧修订的编辑入口。

直接打开包内静态HTML时，可以阅读和导出草稿；导出不等于保存。需要离线应用时，用`python -m reviewproto attention-apply 草稿路径 --workspace 分析目录`，再`attention-recover`并重开核对。普通使用从桌面打开结果即可直接保存。

分析前的结果页会说明尚无保存分析；候选接收和工程回放均保留其实际身份。输入见[输入说明](ATTENTION_INPUT.md)，生成见[分析说明](ATTENTION_CANDIDATES.md)，数据规则见[契约](ATTENTION_CONTRACT.md)。
