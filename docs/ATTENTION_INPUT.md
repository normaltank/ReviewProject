# 输入、换A与下一批材料

这是[可复用关注工具](specs/b-attention-reuse.md)的普通本机路径。运行 `python -m reviewproto desktop`，从主窗口操作；所有原件、输入、分析包和下载仍留在本地可信编辑目录。

## 从新材料开始

1. 在本机窗口点击**新建分析**，粘贴一份评语，点击**将这份评语加入清单**；有多份就继续加入。原话及换行保留。
2. 如需与A比较，在关注清单页录入A的完整条目。A可不提供，也可组织为多个部分。
3. 原分、来源位置、记录名称和分组按需展开填写；不填来源位置时，工具只声明这是手工转录，不冒称已定位原件。已导入材料可从展开的入口选择普通意见。
4. 在**核对整份清单**查看本次材料，点击**保存材料，建立分析…**。选择保存位置后，回本机窗口点击**分析评语**。已有目录不会被覆盖。

选中清单中的条目可以修改；表单中尚未加入的内容会阻止建包。更换B批次时另建独立分析，原有材料保持。

建包只冻结材料，初始观点/主题/关系为空；不会从某个旧样例复制结论。无A新包为修订0，初始提供A时通过显式A事务到修订1。后续整理与保存沿用[关注分析契约](ATTENTION_CONTRACT.md)：从桌面打开结果页后直接“保存修改”，当前概览、明细和图统一使用最新保存修订；静态导出只是草稿。

## 在原分析中换A

先**打开已有分析**，展开**材料与恢复…**，点击**修改A参照（可选）**，核对窗口显示的目标包。填写新的完整A版本、部分、条目、修改者声明和理由，再**保存新的关注清单**。修改内容应使用新版本名。

B记录、分析和观点身份保持，旧A及历史保留，旧对应和清单外解释进入待核，需逐方面纠正。A只作内容参照，不成为强制评分标准。若主窗口切换到了另一个包，旧A录入窗口会拒绝提交，请从正确包重新进入。已有A清单文件可用当前CLI的`attention-import-a`导入。

## B变化或换下一批

输入准备窗口建包后保留清单。修改、增加或移除B条目，再核对并建立另一个独立包；不同材料也可从新窗口开始。原包保持其来源版本、观点和历史，新包从空分析开始。

本版没有原包内B替换及旧观点跨版本迁移。旧来源字节、工作区修订或文件位置失效时，恢复/打开会保留旧快照并标待核，普通编辑拒绝；可还原原绑定后重开，或用当前材料另建分析。不要覆盖旧输入来接续新B。

## 保存与备份

新普通入口把B快照放在包内`inputs/b-input.json`，A初始版本及后续版本各保存独立文件。换A不改写绑定B的清单。关闭本机写入后备份整个包及所绑定工作区/原始来源；仅HTML不够恢复。移动包后绑定仍按原路径校验，不自动换源。

输入校验失败会保留当前已打开包并拒收；如提示页面输出失败，数据库可能已提交，请按窗口给出的目标包恢复并核对修订。不要修改补丁修订号或覆盖输入来绕过提示。操作、报告和备份均继承原材料权限。
