# 输入、换A与下一批材料

这是[可复用关注工具](specs/b-attention-reuse.md)的普通本机路径。运行 `python -m reviewproto desktop`，在“B关注分析”区操作；所有原件、输入、分析包和下载仍留在本地可信编辑目录。

## 从新材料开始

1. 选择**准备A/B输入并建立独立分析**。在B页填写记录锚点/名称、原件定位、普通可见性和逐字原话，按需填材料组。每个原分填写标签及原值，点击加入原分；一条记录可无分或有任意多项。原话、换行与原分空格保留。
2. 点击**B条目加入 / 保存到清单**，逐条重复。选中清单条目可改转录和原分，再保存；新建/清空表单用于下一条，移除只影响待建包清单。材料组是自己的声明，不代表已核实教师或轮次。
3. 已有导入工作区时，可选**选择已导入工作区普通分区…**，选择所需普通分区并加入清单。私密分区不进入分析；同一来源的多个普通分区仍按一条记录计数，材料组声明应一致。此处复用已有抽取，不支持随意Word表式自动解析。
4. A可暂不提供。需要时在A页填版本，加入部分和完整A条目/定位；条目选所属部分。可以保留空部分，也可以不设部分；有部分时每个条目须选定所属部分。保留“往往”“可以”“必要时”等原话限定。
5. 切到**核对整份清单**检查原话、原分、定位、材料组和完整A。表单中未加入的内容会阻止建包，请先保存或清空，避免悄悄遗漏。
6. 点击**核对并建立独立新包…**，选择可信父目录，工具创建一个新子目录并返回位置。已有目录不会被覆盖。回本机主窗口**打开关注页**继续整理观点、方面、主题、关系和A对应。

建包只冻结材料，初始观点/主题/关系为空；不会从某个旧样例复制结论。无A新包为修订0，初始提供A时通过显式A事务到修订1。后续整理与保存沿用[关注分析契约](ATTENTION_CONTRACT.md)：下载是草稿，实际应用后恢复/重开，当前概览、明细和图才统一更新。

## 在原分析中换A

先**打开关注分析包**，选择**录入A参照并显式换版**，核对窗口显示的目标包。填写新的完整A版本、部分、条目、修改者声明和理由，再**将此A版本显式导入已打开包**。修改内容应使用新版本名。

B记录、分析和观点身份保持，旧A及历史保留，旧对应和清单外解释进入待核，需逐方面纠正。A只作内容参照，不成为强制评分标准。若主窗口切换到了另一个包，旧A录入窗口会拒绝提交，请从正确包重新进入。已有A清单文件仍可走原JSON导入入口。

## B变化或换下一批

输入准备窗口建包后保留清单。修改、增加或移除B条目，再核对并建立另一个独立包；不同材料也可从新窗口开始。原包保持其来源版本、观点和历史，新包从空分析开始。

本版没有原包内B替换及旧观点跨版本迁移。旧来源字节、工作区修订或文件位置失效时，恢复/打开会保留旧快照并标待核，普通编辑拒绝；可还原原绑定后重开，或用当前材料另建分析。不要覆盖旧输入来接续新B。

## 保存与备份

新普通入口把B快照放在包内`inputs/b-input.json`，A初始版本及后续版本各保存独立文件。换A不改写绑定B的清单。关闭本机写入后备份整个包及所绑定工作区/原始来源；仅HTML不够恢复。移动包后绑定仍按原路径校验，不自动换源。

输入校验失败会保留当前已打开包并拒收；如提示页面输出失败，数据库可能已提交，请按窗口给出的目标包恢复并核对修订。不要修改补丁修订号或覆盖输入来绕过提示。操作、报告和备份均继承原材料权限。
