# 数据与标注契约

当前产品是可变A/B的关注分析，目标以[业务规格](specs/b-attention-distribution.md)为准。具体对象、补丁、修订和恢复见[关注分析契约](ATTENTION_CONTRACT.md)。旧数据读取与当前写入通过独立适配层衔接。

## 权限与材料

原件、输入、分析数据库、候选响应、HTML、草稿、日志和备份整体继承原材料权限。真实材料限本地可信编辑目录，不进入仓库、合成测试或未经授权的外部请求。折叠、隐藏和本机页面均不提供身份隔离；能读取文件或会话页面的人可以读取其中内容。修改者声明是审计记录，不是认证账号。

只选择普通意见分区。`author_visible`与`visibility_unknown`保留原值；后者不等于允许公开或外发。`internal_only`不得进入当前关注分析。论文及原分按需帮助理解，不自动生成论文专业复审任务。

仅在使用者明确开始模型分析后发送所选普通评语原话及本次 A。原分、来源路径、身份字段与未选分区留在本机。个人凭据由本机加密存储，用户授权的私有试用包可带共享凭据。凭据不进入分析包、日志、补丁、HTML 或 Git。操作见[使用指南](USER_GUIDE.md#开始分析与核对)。

## 原话、原分与定位

- 转录输入保留原话、换行和任意评分标签及原字符串；转录锚点不是原生Word坐标。
- 历史来源保留`source.docx`、`source.csv`或`source.json`的逐字节副本及来源SHA-256。普通分区和原分须与当前受控解析结果一致，不能直接相信旧缓存。
- 历史表单中，评分原标签与`raw_value`原样保留；解释出的数值与空白、不适用、无法解析或越界状态分开，不能用归一化结果覆盖原分。当前转录原分不强制适用旧四项评分表型。
- 审稿关系、教师、轮次及正式稿件配对未知时保留未知，文件名或日期相似不足以配对。材料组仅是显式声明。

引用采用`source_id + section_id + [start,end) + quote`，偏移为冻结分区中的零基Unicode码点，严格满足`text[start:end] == quote`。重复句必须选定实际区间，不以首次字符串匹配代替定位。Word段落间保留换行，定位指向实际表、行、格和段落；当前解析器不支持或有隐藏、修订、编号、合并等歧义的表型应拒收，不能以旧缓存绕过。

## 历史来源只读接入

`legacy_source.read_source_workspace`只读历史SQLite及冻结原件，重新核验数据库身份、版本、路径、文件指纹、支持表型、普通分区和原分。只返回当前输入需要的来源、修订、分区与评分，不加载旧framework、候选审核或状态刷新，不修改历史数据库、原件及人工记录。

原件变化、绑定失效、来源不可读或分区越权须明确处理。旧分析快照和历史保留，新编辑拒收；不得静默改绑到另一个来源。无关旧框架文件损坏不应阻断已经核验的普通材料。历史原件未被删除，也不为保留历史而继续提供旧写入产品。

## 分析与人工纠正

观点可以含多个方面。限定、理由、条件、动作、表达作用、套话候选、主题成员、带角色及范围的关系、A对应与清单外解释分别保留。主题相同不等于同一判断，原句逐字命中也不证明解释或关系正确。

`working`、`needs_review`和`confirmed`描述分析处理状态。人工确认表示核对本项目对数据的处理，不表示认可B的专业判断。模型候选及重跑不覆盖人工成果，也不自动升级确认。未处理、部分处理、失败与已经核对但没有对应须按实际状态分别表达。

A条目保留完整原话、限定及版本，只作内容参照。可以多重对应、部分对应、相关、未定或有依据的清单外；未提及不代表不关注，频率不变成权重。结合原分也不能无据推断给分原因、审稿人严宽或专业正确性。

## 保存与恢复

当前结果页通过桌面临时回环会话调用`AttentionWorkspace.apply`，只使用已有SQLite事务和历史。新编辑统一生成`attention-patch/2`。历史`attention-patch/1`在窄的兼容适配位置读取转换，历史内容及幂等身份不重写。

事务核对分析身份、当前修订、来源、A版本、证据及全部编辑；失败整批回滚。同一补丁重试幂等。来源失效、冲突、会话关闭和保存失败不会把页面草稿冒称已保存；输出失败可能已提交，应先恢复并核对。明细、统计与图形使用同一保存态。

静态HTML不含写入会话凭据；导出草稿不等于保存。关闭本机写入后备份完整分析目录及绑定来源，恢复到新位置并重新核验。只有HTML不足以恢复数据库和修改历史。
