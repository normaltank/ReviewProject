# Triage labels

使用五个默认状态标签，名称与技能的规范角色一致：

- `needs-triage`：维护者需要评估。
- `needs-info`：等待补充信息。
- `ready-for-agent`：规格足够明确，可以交由代理实现。
- `ready-for-human`：需要人工判断或实现。
- `wontfix`：不予处理。

分类沿用仓库现有 `bug` 和 `enhancement`。已完成 triage 的工作项应有一个分类标签和一个状态标签；状态冲突时交由维护者决定。

调用 `/triage` 时遵循技能本身的核验、推荐和确认过程。该技能发布的工作项或评论必须以以下声明开头：

> *This was generated by AI during triage.*
