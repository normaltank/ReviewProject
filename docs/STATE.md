ReviewProject 读取每批 B 评语，整理关注内容及关系，对照当批可选的 A 清单。使用者从关注图或逐条阅读核对原话和解释并保存。业务边界见[业务规格](specs/b-attention-distribution.md)，操作见[使用指南](USER_GUIDE.md)。
