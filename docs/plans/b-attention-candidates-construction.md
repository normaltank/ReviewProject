# 内容与位置候选施工计划

更新：2026-11-15。规格：[B内容与A位置候选分析v1](../specs/b-attention-candidates.md)。起点：main `d78cb256e5ccf5d3111b87771f583df3f3638692`，PR #25已交付跨批输入、编辑和保存；本轮补原始B分析与直观位置链。GitHub任务及PR记录实施状态，本文件维护验收和依赖。

## 实施顺序

1. **C0 固定范围与任务图。** 核对既有抽取、保存、界面及本机资源；提交规格和计划，发布同版本父子工作项。已完成只读审计，不再开展外部AI征询。
2. **C1 本机分析到受控导入。** 从analysis包的全部所选评语段落构造快照，先理解B、再独立对照A，校验逐字证据与结构，保存可审计运行，提供CLI生成/回放/预览/接收路径。接收遵守既有事务和待核规则。复用已安装本机资源，通过明确资源路径及独立状态日志管理本工具拥有的服务。此票可单独用合成包演示完整分析/导入。依赖C0。
3. **C2 保存态到直观位置与回查。** 按可变A/B构造位置视图，支持多处归属、清单外、待核、无A、旧A及记录去重；联动明细和原话，保留非图形入口。此票以已保存合成包独立验收。依赖C0，与C1文件隔离并行。
4. **C3 普通界面完整候选路径。** 集成C1与C2，在普通Tk路径选择范围、本机生成、预览建议位置、接收为待核、回查纠正、保存及重开。长操作和目标变化安全，草稿不混入正式统计。依赖C1、C2均已集成且通过相关验收。
5. **C4 新输入实测与最终交付。** 在实现冻结后使用未参与设计的新合成A/B，实际本机推理并独立核对语义忠实度，实际界面操作，完整检查及双轴审查；集中返修、终版CI、授权PR/main交付。依赖C3；不因格式测试通过而关闭语义缺口。

## 所有权与集成

统筹负责规格、任务、基线、验收数据和发布；C1拥有候选核心、提供方、CLI、本机资源入口及对应测试；C2拥有位置投影、渲染资源和对应测试；C3拥有普通候选控制器/界面、候选覆盖层及完整路径测试。共享文件先报告统筹协调，不跨票重构。

各实施票独立分支与工作树，交接前同步最新集成头并重验。独立merger逐份核对同步SHA后串行集成；统筹不同时写入集成树。首次有效集成后建立草稿PR。双轴审查固定同一base/target，由一名新代理集中返修，审阅者复核。

稳定运行树继续保留已交付版本；本轮不改当前真实数据包、历史未提交成果或其他代理工作树。模型运行使用本任务状态/日志，禁止覆盖旧运行记录或接管无所有权进程。

## 验收与验证

- **V1 输入与先后顺序：** 变化A/B标识、数量、结构；覆盖合并记录全部段落；无A、先B后A；请求证实B阶段没有A；上下文容量及未处理范围明确。
- **V2 证据与提供方：** 逐字位置、重复片段、Unicode、幻觉拒绝；否定、条件与备选不丢失；回环限制、重定向、错误和截断；实际推理与回放区分并有原始运行记录。
- **V3 保存：** 生成不改包，接收新增待核，幂等、过期、并发、历史、失败恢复；人工成果不被覆盖，重开一致。
- **V4 位置：** 多A、清单外、待核、无A、旧A、筛选和记录分母正确；候选建议与正式统计清楚分开；点击回到证据和编辑。
- **V5 普通路径：** 实际Tk从新输入到生成、预览、接收、纠正、保存、重开；真实Chrome检查图形与非图形明细及规模场景。
- **V6 语义：** 先冻结新合成案例与预期，再实际本机调用；保留模型/提示/协议/请求/响应/用量和判断依据，独立核对我们的处理，不评判B专业正确性。遗漏、误解或未覆盖能力如实记录并修复。
- **V7 终版：** 相关测试、完整unittest及scripts/check.ps1（含真实Chrome、零跳过）、固定版本Spec/Standards及返修复核、最终CI终态；提交、推送、合并与运行树更新分别留证据。

完成条件是上述路径可复用且证据支持实际声称的范围。若本机模型在某项语义能力上未达到验收，该项保持开放，不能改写为“仅基础设施已完成”而宣称本轮目标达成。
